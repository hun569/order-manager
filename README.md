# 공사·구매 발주관리

결재문서(품의서·기안지)를 등록하면 발주 목록으로 정리하고, 발주 이후 진행 단계를 관리하는 웹 앱입니다. HTML 파일 하나로 동작합니다.

## 사용법

1. `order-manager.html`을 Edge 또는 Chrome으로 엽니다.
2. **[+ 결재문서 등록]**에 결재문서 PDF(또는 스캔 이미지)를 끌어다 놓습니다.
   - 문서번호, 일자, 제목, 담당자(결재란 '담당'), 업체·금액(빨간 테두리 칸), 비고를 읽어 자동으로 채웁니다.
   - 노란 칸은 원문과 대조해 확인한 뒤 저장합니다.
3. 발주 → 착수 → 완료(준공·납품) → 계산서 접수 → 대금 지급 단계로 관리합니다.
4. 업체를 고르면 업체별 발주 현황을 보고 출력·엑셀 저장할 수 있습니다.
5. 기존 발주 현황 엑셀(.xls/.xlsx) 불러오기, 엑셀 내보내기, 백업·복원을 지원합니다.

## 데이터

- 데이터는 사용하는 PC의 브라우저 저장소(IndexedDB)에만 저장됩니다. 서버로 보내지 않습니다.
- 글자 인식(OCR)도 브라우저 안에서 처리합니다(Tesseract.js). 처음 한 번 한글 인식 데이터를 내려받습니다.
- 정기적으로 **[백업]**을 받아 두세요.

## 사용 라이브러리

- [PDF.js](https://mozilla.github.io/pdf.js/) 3.11.174
- [Tesseract.js](https://tesseract.projectnaptha.com/) 5.1.1
- [SheetJS](https://sheetjs.com/) 0.18.5
